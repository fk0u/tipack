Sebelum mulai.

Apa bedanya dengan Ninite?

Ninite hanya untuk Windows dan hanya memasang. TIPACK berjalan di Windows, macOS dan Linux (x64 & ARM64), memakai package manager resmi (winget, Homebrew, apt/dnf/pacman/zypper, Flathub), punya wizard dengan penjelasan, Doctor yang memperbaiki masalah, Tune-Up, Debloat, laporan masalah otomatis, dan sepenuhnya open source (MIT).

Aman? Apa saja yang dilakukan di laptopku?

Semua aplikasi diambil dari sumber resmi, bukan file dari situs acak. Tidak ada telemetri. Tune-Up menampilkan ukuran sebelum menghapus, dan Debloat Windows membuat restore point dulu. Kode bisa dibaca di GitHub, dan detailnya ada di dokumen keamanan.

Bagaimana kalau ada yang gagal atau stuck?

Buka menu Doctor; kebanyakan masalah bisa diperbaiki otomatis. Kalau belum beres, pilih Laporkan Masalah: log disensor, disalin ke clipboard, lalu form GitHub Issue terbuka dengan info sistem terisi.

Bisa dipakai untuk satu lab atau kelas sekaligus?

Bisa. Buat pilihan di atas, unduh tipack.json, lalu di setiap laptop jalankan setup.ps1 -Config tipack.json atau bash setup.sh --config tipack.json. Konfigurasi juga bisa berupa URL.

WSA (Android di Windows) masih bisa?

Tidak. Microsoft menghentikan WSA pada 5 Maret 2025. TIPACK menyarankan Android Studio Emulator untuk develop, atau BlueStacks untuk menjalankan APK.

Di HP Android bisa?

Bisa lewat Andronix: pasang Ubuntu di Android, masuk ke distronya, lalu jalankan perintah Linux yang sama.
