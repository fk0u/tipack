# Dokumentasi TIPACK

## Ringkasan 30 detik

| OS | Perintah |
|---|---|
| Windows | `irm https://tipack.kousozo.tech/install.ps1 \| iex` |
| macOS / Linux | `curl -fsSL https://tipack.kousozo.tech/install.sh \| bash` |

Lalu pilih **Wizard Preferensi** → jawab pertanyaan → **Keranjang & Install** → Enter. Selesai.
